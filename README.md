\# BMI Calculator



A simple Python command-line application that calculates Body Mass Index (BMI) based on the user's weight and height.



\## Features



\- Accepts weight in kilograms

\- Accepts height in meters

\- Calculates BMI using the standard formula

\- Displays BMI rounded to 2 decimal places

\- Classifies BMI as Underweight, Normal, Overweight, or Obese

\- Validates negative and zero values

\- Handles non-numeric input

\- Allows multiple BMI calculations



\## Formula



BMI = Weight (kg) / Height² (m)



\## Technologies Used



\- Python

\- input()

\- Basic arithmetic

\- Exception handling
